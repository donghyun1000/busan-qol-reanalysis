# 데이터

모든 파일은 부산 16개 구·군이 같은 순서(중구 → 기장군)로 들어 있습니다. 인코딩은 UTF-8(BOM)입니다.

## 파일

| 파일 | 내용 | 출처 |
|---|---|---|
| `indicators_raw.csv` | 지수에 들어간 지표의 원값 | 팀 저장소의 영역별 산출 파일에서 추출 |
| `qol_team_v1_20251229.csv` | 영역별 QOL 점수 (0~1). 당시 회귀분석에 쓴 버전 | 팀 저장소 `total_QOL.csv` (2025-12-29 커밋) |
| `qol_team_final.csv` | 교육 영역에 학교생활만족도를 추가한 최종본 | 팀 저장소 `total_QOL.csv` (최종) |
| `satisfaction_2025.csv` | 삶의 전반적 만족도, 거주지역의 전반적 만족도 | 부산광역시 「2025 부산사회조사」 '삶에 대한 만족감과 정서 경험' |

지표의 원자료는 KOSIS, 공공데이터포털, 부산광역시, 국토교통부 자료를 팀이 정리한 것입니다.

## 영역별 산식 (팀 산정 기준)

- **경제:** 추정평균소득 0.5 + 1인당 지방세 0.5
- **교육:** 교원당 학생 수(역) 0.5 + 학생당 학교 수 0.5
- **주거교통:** 월세(역) 0.20 + 월세보증금(역) 0.15 + 전세보증금(역) 0.15 + 지하철역 수 0.30 + 버스정류장 수 0.20
- **인프라:** 생활인프라 0.5 + 비혼잡(인구밀도의 역) 0.2 + 녹지 0.3
- **안전:** 범죄(역) 0.35 + CCTV 0.30 + 교통사고(역) 0.25 + 화재(역) 0.10
- **종합:** 경제 0.25 + 주거교통 0.25 + 인프라 0.20 + 교육 0.15 + 안전 0.15

모든 지표는 MinMax 정규화(0~1)했고, (역)은 낮을수록 높은 점수가 되도록 뒤집었습니다.
